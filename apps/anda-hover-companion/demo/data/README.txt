ANDA COMPANION (NOTULA): THE DEMO'S OWN FOLDER

While a folder named "data" stands beside AndaCompanion.exe, the program keeps everything
it stores in it: settings, the two to-do lists, notes, prompts and the optional usage counts.
Nothing is written to your Windows profile, and removing the demo is deleting its folder.

Delete this "data" folder (with the program closed) and the program uses its normal place
instead: %APPDATA%\AndaCompanion.

All data in the demo is fictional. A prototype, not an FDA product.
