# Trial sheet: does the new design help in daily work?

Five everyday tasks, timed, so that "feels more professional" can be checked against "is faster and easier to use".
All data is fictional. Use the **browser simulation** (`mockup/windows-simulation.html`) for both. For the new way, open it as it is. For the earlier way, open it with `#all` added to the end of
the address, then in Settings, Look and feel, choose **K · Graphite Quiet** (the earlier default). Tasks 3 to 5 depend on features that are new in round 18, so the earlier way is the one
the person would have used before; it is written in the table.

**Who.** At least three people who do project management work every day. Please do not use the author. Each does the five tasks both ways, alternating which comes first, so that
practice does not decide the result.

**How.** Read each task aloud. Start a stopwatch when the person starts, stop it when they say "done". Write down the time, any wrong turn, and anything they say.
Please do not explain the screen unless they are stuck for a full minute (write that down as "stuck").

| # | Task | Earlier way | New way | Done when | Time, earlier | Time, new | Wrong turns / notes |
|---|---|---|---|---|---|---|---|
| 1 | Find out how late or early ANDA 216482 is against its goal | Card in K | Card in T (Pocket Plain) | They say the number of days and "later" or "earlier" | | | |
| 2 | Copy a status line for ANDA 216482 and paste it into the sample email | The *Copy status* chip in K | *Copy status* on the card, or the S key | The sentence is in the email | | | |
| 3 | Open ANDA 214990, which was looked up a minute ago | Type the number in the lookup box | Press its chip under *Recent* | The card for 214990 is open | | | |
| 4 | Find which ANDAs need a look today | Tray menu, *Watch list* | Tray menu, *Today…* (needs `#all`) | They name the ones marked urgent or with a WATCH line | | | |
| 5 | Make the text larger, then switch back | Not possible in the earlier design (skip, write "none") | Settings, How it starts, *Larger text*, then *Standard text* | The text size changed and returned | | | |

**After the tasks, ask each person three questions, and write down their words:**

1. Which of the two would you rather open fifty times a day, and why?
2. Was there anything on the card you did not understand or did not trust?
3. What did you look for that was not there?

**What counts as a result.** The new design helps if, for most people, tasks 1 to 3 are faster or equal and nobody is slower by more than a few seconds on any task, and if
nobody reports something they did not trust. Three people cannot show a statistical difference. They can show a problem.
Anything unexpected goes into `VERIFICATION.md` as a finding, not into a claim.

**What this sheet cannot show.** Whether the design holds up over weeks, on a real portfolio file, with real ANDAs, at a managed FDA computer's display scaling, or with
leadership, who may keep no portfolio at all (Today is of little use to them).
