ANDA Companion (Notula) for Edge

Prototype, not an FDA product. It makes no network requests of its own. Everything stays in this browser profile unless you connect the desktop app on this computer.

My spreadsheet

Excel (.xlsx) or CSV. Read here in the browser, never uploaded; the rows are kept in this profile so the extension works offline. It shows only what your sheet says: a forecast or progress that is not in it shows as "—", never an estimate. A notes folder needs the desktop app.

Extra closures

One per line: a date, then a name. Weekends and federal holidays are always included (U.S. federal calendar, OPM). Closures announced at short notice are not predicted, so add them here. This only flags the date; it never says how a goal-date rule applies.

Ways to start it

Edge leaves out a suggested shortcut that another extension or Edge itself already uses, and shows it here as not set. Choose another one in Edge's shortcut page.

Other ways: the right-click menu on selected text, and the toolbar button. A middle-click trigger is not offered here on purpose: an extension can only watch the mouse by running a script on every page you open, and this one is built to run only when you ask. The Windows app offers a middle-click option.

What this extension can and cannot do

It runs on a page only when you press a shortcut, use the right-click menu or click its button, and only on that tab (the "active tab" permission). It has no permission to read pages you have not asked about, to use your history, or to call any website. It does not use AI.
